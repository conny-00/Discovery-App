Características y modulos 

La aplicación rompe con el esquema de los folletos estáticos tradicionales mediante una experiencia visual e interactiva construida bajo los siguientes flujos:

1.  **Splash Screen Animado:** Transición fluida inicial con el logotipo institucional y carga asíncrona de recursos.
2.  **Infografía Interactiva Principal:** Secciones expandibles y dinámicas que desglosan áreas clave: IA, Ciberseguridad, Cloud Computing, Redes y Programación.
3.  **Módulo de Campo Laboral:** Visualización creativa de las oportunidades profesionales (Big Tech, Startups, Consultoría).
4.  **Mapa de Especialidades:** Red visual interactiva de las líneas de especialización de la universidad.
5.  **Test Vocacional Reactivo:** Cuestionario interactivo de 5 preguntas ("¿Es Sistemas Computacionales para ti?") con diagnóstico de afinidad calculado en tiempo real.
6.  **Contacto Directo y Código QR:** Botón Flotante (FAB) con *Intents* implícitos hacia WhatsApp/Correo de admisiones y un código QR escaneable para descargar el plan de estudios en PDF.
